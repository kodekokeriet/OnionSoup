# Onion Soup roadmap

What is shipped is listed in [CHANGELOG.md](CHANGELOG.md). This page lists work in progress and ideas for later.

## In progress

- **Battery life**: an idle mode in the Onion Soup apps, CPU back to normal speed after video playback, and WiFi turned off again when the App Store is closed.
- **SSH host keys** kept across full updates, so SSH clients do not warn about a changed key after updating.

## Planned

- **Manage App Store sources in the App Store**: add and remove catalog sources from a menu instead of editing `appstore_sources.txt`, with each entry showing which source it comes from and a clear warning for unofficial sources.
- **Rom hacks in the Game Store**: a source of rom hack patches, using the rom hack support that is already in the Game Store.
- **Better game list**: further improvements to the existing MainUI game list.
- **Native app template**: documentation and a C/SDL template for apps that run directly on the Miyoo without an emulator, published through the App Store.
